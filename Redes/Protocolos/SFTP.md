# SFTP

SFTP (SSH File Transfer Protocol) es un protocolo de transferencia segura de archivos que provee acceso a los archivos, transferencia y gestión sobre un procedimiento confiable. Corre sobre un protocolo SSH, típicamente en el puerto 22, asegurando que los archivos se transfieran encriptados. Ofrece mas seguridad que el protocolo tradicional FTP, encriptando los datos en tránsito y previniendo la intercepción no autorizada. Soporta features como resumir transferencias interrumpidas y operaciones desde el filesystem.
