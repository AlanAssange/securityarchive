# Threat Modelling

Threat modelling es un ejercicio metodológico que consiste en identificar la superficie de ataque. Esto incluye a las APIs, flujos de negocio, funcionalidades que las APIs proveen y cómo son accesibles, etc.

Se examinan los riesgos y vulnerabilidades de la lógica, los controles de acceso y los servicios externos que son llamados via código. Luego, las probabilidades de que pueda existir un ataque y el correspondiente impacto, las consecuencias.

Finalmente, como mitigar estos posibles daños.

## Que tiene la corporacion que los atacantes quieran?

- Informacion personal: Datos del consumidor
- Informacion financial: Datos del banco, tarjetas de credito
- Datos corporativos: Espionaje, IP, datos corporativos
- Fraude: Profit financial, libre uso.
- Infraestructura critica: Activismo, terrorismo.

## Como estan utilizadas las APIs en el negocio?

- Funcionalidades web
- Aplicaciones tipo mobile
- Microservicios internos
- Asociados - Servicios externos acceso via API

## Formula Threat Modelling

Threat Modelling también es una fórmula para calcular el riesgo de los ataques, la vulnerabilidad, probabilidad e impacto. Este ejercicio permite sacar el riesgo completo de cada amenaza y priorizar a su vez la mitigación de las mismas.
