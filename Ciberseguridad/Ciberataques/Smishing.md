# Smishing

Smishing, una aleación de SMS y phishing, es una forma de ciberataque que utiliza SMS como recipientes para divulgar información sensible o tomar acciones que generan daños. Los atacantes típicamente impersonan entidades confiables como bancos u agencias gubernamentales para que las víctimas clickeen en links maliciosos o descargen aplicaciones potencialmente dañinas para el usuario. Estos mensajes crean una necesidad de urgencia para manipular a los usuarios.
