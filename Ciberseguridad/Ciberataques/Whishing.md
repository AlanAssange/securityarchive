# Whishing

El Whishing (wireless y phishing) es un ciberataque en el que el objetivo es un usuario de una red inalámbrica, particularmente redes públicas de wifi. Los atacantes crean access points inalámbricos o comprometen los existentes para interceptar el tráfico en red o redirigir a los usuarios hacia sitios web maliciosos. Estos access points falsos se mimetizan con los legítimos, engañando a los usuarios para que se conecten hacia sus redes wifi y exponiendo su información sensibles. Los ataques whishing pueden llevar al robo de credenciales de login, datos financieros o información personal.

Para protegerse de ataques de tipo whishing, los usuarios deben utilizar VPNs o evitar las transacciones sensibles en redes de wifi públicas.
