# Zero Day

Una vulnerabilidad de día cero (zero day) es una falla de seguridad del software que tanto el fabricamente como los desarrolladores de exploits desconocen, lo que la deja potencialmente explotable. Cuando los atacantes descubren y explotan una vulnerabilidad de este tipo antes de que el creador del software pueda desarrollar una solución, se denomina ataque de día cero. Estos atacantes aprovechan el lapso del descubrimiento y la aplicación del parche cuando el sistema es altamente vulnerable. Los ataques de día cero se pueden utilizar con diversos fines maliciosos como robo de datos, vulneración del sistema o como parte de campañas de ataque más grande. La defensa contra los ataques de día cero requiere medidas de seguridad proactivas, ya que las defensas tradicionales son ineficaces ante amenazas desconocidas.

Un exploit de tipo zero-day es un método que los hackers utilizan para atacar a los sistemas con una vulnerabilidad no identificada.

Un ataque de tipo zero-day es el uso de un exploit zero-day para causar daño al sistema afectando por la vulnerabilidad descrita.

## Ejemplos de ataques zero day.

2021: Chrome zero-day vulnerability

In 2021, Google's Chrome suffered a series of zero-day threats, causing Chrome to issue updates. The vulnerability stemmed from a bug in the V8 JavaScript engine used in the web browser.

En 2021, google chrome sufrió varias amenazas de tipo zero day, ocasionando problemas en Chrome para actualizarse. La vulnerabilidad se encontraba en un bug en la versión 8 del engine de javascript utilizado en el navegador.

2020: Zoom

Una vulnerabilidad fue encontrada en Zoom, involucrando hackers que podían acceder a las PCs del usuario remotamente si estaban corriendo versiones antiguas de windows. Si el target era el administrador, el hacker podía tomar control completo de la PC y acceder a todos sus archivos.

## Como protegerse de ataques Zero Day

- Mantener el software actualizado. Esto se debe a que los vendedores incluyen parches de seguridad para cubrir vulnerabilidades identificadas en nuevos releases.

- Utilizar solo aplicaciones esenciales. Mientras más software se tenga, mas vulnerabilidades tendrás. Pueden reducir el riesgo de la red utilizando solo las aplicaciones necesarias.

- Utilizar un firewall. Los firewalls juegan un rol esencial en proteger el sistema sobre las amenazas zero-day.

- Educar al personal en buenas prácticas.
