# Drive By Attack

Un ataque de tipo Drive-by es un ciberataque en el que el código malicioso es automáticamente descargado y ejecutando en un sistema de usuario simplemente al visitar un sitio web malicioso. El usuario no necesita clickear en nada o interactuar con la página, cargar el sitio es suficiente para activar el ataque.

Estos ataques utilizan kits que lanzan automáticamente una descarga. Los kits de exploit son piezas de software malicioso, creada por hackers que identifican vulnerabilidades en dispositivos o navegadores web. Estas vulnerabilidades son utilizadas para que el proceso de descarga automática sea llevado a cabo y se produzca el ataque. Este tipo de ataques están diseñados para infectar dispositivos, robar información o causar daños a los datos.

## Tipos de ataques drive by

- Sin autorización: No hay una acción del usuario que ocasione una descarga. En otras palabras, el ataque es lanzado simplemente cuando se visita un sitio web comprometido, sin necesidad de interacción con la página, ni un solo click.

- Con autorización: A veces, hay una interacción con el usuario como por ejemplo, al cerrar una ventana. El botón parece legítimo, sin embargo puede lanzar una descarga maliciosa una vez que este es presionado. El hecho de clickear, activará el evento.

## Como pueden los ataques drive-by ser detectados y prevenidos?

Para prevenirlos, se recomienda:

- Evadir sitios web sospechosos: Se recomienda revisar que tengan certificados de seguridad válidos.
- Si estás en duda, no clickees: Para evadir ser víctima de estos ataques, es importante verificar que el link es legítimo antes de clickearlo. Prestar atención a las publicidades y todo lo que prometa un premio al entrar o te solicite tus datos como input es recomendable. Observar si las imágenes son de baja calidad o tienen errores de ortografía. También es posible instalar extensiones en el navegador de tipo ad-block que puedan ayudarte a esquivar misclicks que lleven hacia estos ataques. Asegurarse que el ad-block también proviene de un sitio confiable.
- Solo descargar software de sitios web legítimos.
- Mantener el software actualizado hasta la fecha, incluyendo el sistema operativo.
