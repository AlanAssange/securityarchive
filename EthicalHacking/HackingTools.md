# Hacking Tools

Las herramientas de hacking comprenden un rango de softwares utilizados para exploración de redes, auditorías de seguridad y pruebas de penetración. Esto incluye scanners de redes como _Nmap_, escaneo de vulnerabilidades como _Nessus_, crackers de passwords como _John The Ripper_ y frameworks de exploits como _Metasploit_. Wireshark para analisis de paquetes, _Burp Suite_ para testing de seguridad en aplicaciones web y _Aircrack-ng_ para auditorias de redes wifi. Mientras que estas herramientas tienen propósitos legítimos en ciberseguridad para identificar y hallar vulnerabilidades, pueden ser utilizadas para actividades maliciosas. El uso ético requiere adherirse a las vías legales. Entender estas herramientas escrucial para la ofensiva y defensiva en las prácticas de ciberseguridad.
